# 寝坊ダッシュ

[今すぐプレイ](https://lushlifelikenightflight-hue.github.io/iroirona-jujika-nebou-dash/)

ライブ当日に5人全員が寝坊。たかしを操作して仲間を迎え、ゴシックの街を走り抜ける、全5面の横スクロールアクションです。1人でもゴールでき、全員が揃うとライブエンディングになります。

たかし＝闇、たける＝炎、ぽにて＝雷、べんぞー＝氷、きんぐ＝光。途中の家／隠し部屋で加入し、「しゃがむ」の上の交代ボタンで加入順に交代。一輪車は18秒間加速。時間切れはタクシーエンディングになり、最後にスコア内訳を表示します。

## v1.8.0のステージ

- 全員エンディングの表記をCongratulations!へ修正。
- 1面は従来の地形・ギミックを維持。
- 2面は高台と広い谷、追い風／向かい風のエリア。空中の移動が風で変化し、追い風を使って谷を越えます。穴の底の家と帰還バネも保持。
- 3面は高低差のある氷床。慣性で滑り、停止・反転が難しくなります。しゃがむとブレーキ。2段のバネから隠し家へ向かう経路は継続。
- 4面は2つの往復足場と、乗ると起動する昇降台。端で一時停止するので乗り継ぐタイミングを考えます。高い屋根へ昇って、谷を越えて進みます。
- 5面は3か所の連続する崩落床。乗って0.7秒で崩れ、床は3.5秒後または転落からの再開時に戻ります。階段状の最後の区間を渡ってボスのいる礼拝堂へ。
- 攻略ヒントを各面の開始時に表示。構造と当たり判定はsrc/stage-gimmicks.mjs／src/data.mjs、表面は既存の石床素材を共用。

## v1.7.0の変更

- きんぐの光は前後・斜め上下の4方向へ同時発射。1つの発射で同じ敵へのダメージは1回。
- べんぞーの氷は2秒間、移動・ジャンプ・しゃがみ・向きの変更に追従。交代後も残り時間まで防御します。
- 交代ボタンは「しゃがむ」の真上。入室ボタンはスティックの上に表示します。
- 3〜5面の終盤に飛行射撃敵を配置。0.45秒の光る予兆のあとプレイヤーへ弾を発射し、後半ほど弾速と再使用を強化。
- ボスの得点は2500。HUD、撃破表示、結果内訳に同じ定数を使用。

## 操作と素材

- タイトル集合画像は縦画面で左右12pxの余白を設けて幅に合わせ、5人全員を中央に表示。横画面も画像全体が収まる高さに調整。
- スマホは縦画面を基準に固定。上部に体力と仲間、中央にゲーム、下部に操作パネルを配置。回転は不要で、画面比に合わせて描画します。左のスティックは倒し加減で速度が変わり、離すと中央へ戻ります。右は能力・ジャンプ。
- スティックと右ボタンを同時操作できます。操作領域の長押しによる文字選択・コピー・画像ドラッグ・メニュー表示を抑制しています。
- 「しゃがむ」を長押し／↓・Sでしゃがみます。離すと立ち上がり、天井が低い場合は低い姿勢を維持。しゃがみ中はゆっくり移動し、一輪車からは降ります。
- v1.6で左右の走り80コマを作り直し、脚の入れ替わりと移動速度に合う再生を改善。一輪車のペダル80コマとしゃがみ10枚も後続の仲間へ反映。交代ボタンは1つで、加入順に次の仲間へ切り替えます。次の交代先と現在のメンバーを表示。
- BGM8曲とSFX15種は導入済みローカル音声工房で新規生成。開始タップでBGMとSFXを有効化。タイトルの「音を聴く」、ポーズの「音声を試す」で試聴できます。上部の「音 ON/OFF」で切り替え、長押しメニューで音量調整。[制作記録](ASSETS.md)
- 滑り台のあとでも「しゃがむ」で加速を解除して左右へ動けます。指を画面の外側で離した場合も移動を解除し、次のスティック操作を受け付けます。
- 1人はソロ、2人は同行メンバーとのユニット、3／4人は欠席者を振り返り、5人は最高のライブを終える結末。実際の加入メンバーの名前と姿を反映します。
- ステージ1〜5は敵6／8／11／14／18体（5面はボス込み）。後半ほど巡回と敵弾が速く、射撃の間隔が短くなります。
- 会話は文のまとまりで改行。話者名を揃え、2行目は台詞の本文位置から表示。
- PCは←→ / A Dで移動、Space / Z / ↑でジャンプ、↓ / Sでしゃがみ、X / Jで能力、C / Kで交代、Eで入室、Esc長押しでメニュー。

- メニューはⅡを700ms長押しで開きます。画面離脱ではメニューを出さず停止し、復帰すると再開。
- 家のドアは室内中央。退出後3秒は保護され、近くの敵弾を消し、敵の動きと射撃を一時停止。
- たけるの家は地上。ぽにては穴の底から帰還バネ、べんぞーは2つのバネを乗り継ぐ高台、きんぐは魔物7体を全員倒すと現れる家にいます。寄り道をしなくても完走できます。
- 低い通路の一輪車はしゃがみ歩きで取得し、立てる場所へ出てから乗ります。
- 5人ライブの縦長画像を生成。画面比に合わせて全体を表示し、文字やボタンで人物を隠しません。
- 各面にバネと滑り台を設置。バネは踏むだけで高く跳ね、滑り台は右へ加速。ジャンプで抜け出せます。

## 起動・検証

Node.js 22以上。追加パッケージのインストールは不要です。

```sh
npm start
```

表示された `http://127.0.0.1:4186` をブラウザで開きます。ポートは`PORT`環境変数で変更可能。

```sh
npm test
npm run check
```

ローカルの `/tests/browser.html` で音源の再生・SFX信号・同時操作・画面サイズ・加入・結末を検証。`/tests/sprites.html` は左右走り、`/tests/actions.html` は左右の一輪車としゃがみの確認画面です。`/tests/mechanics.html` は中央ドア・バネ・滑り台の確認画面です。`/tests/routes.html` は地下・高台・封印・低い通路・縦ライブの確認画面です。`/tests/update-v15.html` は滑走後の入力・会話・1〜5人の結末と画面サイズの検証画面です。検証ページと原画は公開ゲームの配信に含めません。

最新仕様は[更新仕様_v1.6.md](更新仕様_v1.6.md)。基本の5面・能力・スコアは[仕様書.md](仕様書.md)。物理／進行は`src/engine.mjs`、画面は`src/main.mjs`、描画は`src/render.mjs`、スティックは`src/stick.mjs`、メンバー・5面は`src/data.mjs`。

ハイスコア、音量、直近のステージ入口をブラウザ内に保存。続きからは入口で再開。mainへのpush後、GitHub Actionsでテストと素材検査が通った版をPagesへ公開します。

正本はこのREADMEのあるフォルダー。実機iOS／Androidのタッチ・音声は未確認です。提供素材の権利は各権利者に帰属します。
