# 寝坊ダッシュ

[今すぐプレイ](https://lushlifelikenightflight-hue.github.io/iroirona-jujika-nebou-dash/)

ライブ当日に5人全員が寝坊。たかしを操作して仲間を迎え、ゴシックの街を走り抜ける、全5面の横スクロールアクションです。1人でもゴールでき、全員が揃うとライブエンディングになります。

たかし＝闇、たける＝炎、ぽにて＝雷、べんぞー＝氷、きんぐ＝光。途中の家／隠し部屋で加入し、上部の名前を押すと交代。一輪車は18秒間加速。時間切れはタクシーエンディングになり、最後にスコア内訳を表示します。

## v1.1の操作と素材

- スマホは横画面。左の立体スティックを倒すと左右に移動し、倒し加減で速度が変わります。右は能力・ジャンプ。指を離すとスティックが中央へ戻ります。
- スティックと右ボタンを同時操作できます。操作領域の長押しによる文字選択・コピー・画像ドラッグ・メニュー表示を抑制しています。
- 5人それぞれの左右走りを8コマずつ制作。後続の仲間も走り、停止時は立ち姿へ戻ります。立ち／一輪車にも左向きの別画像があります。
- BGMは導入済み音声工房のACE-Stepで新規生成した8曲。原音を保持し、音量とループを仕上げています。[制作記録](ASSETS.md)
- PCは←→ / A Dで移動、Space / Z / ↑でジャンプ、X / Jで能力、C / Kで交代、E / ↓で入室、Escでポーズ。

## 起動・検証

Node.js 22以上。追加パッケージのインストールは不要です。

```sh
npm start
```

表示された `http://127.0.0.1:4186` をブラウザで開きます。ポートは`PORT`環境変数で変更可能。

```sh
npm test
npm run check
```

ローカルの `/tests/browser.html` で音源・同時操作・長押し抑制・加入・結末を検証。`/tests/sprites.html` で5人の左右走りを確認できます。検証ページと原画は公開ゲームの配信に含めません。

仕様と調整箇所は[仕様書.md](仕様書.md)、[改修仕様.md](改修仕様.md)。物理／進行は`src/engine.mjs`、画面は`src/main.mjs`、描画は`src/render.mjs`、スティックは`src/stick.mjs`、メンバー・5面は`src/data.mjs`。

ハイスコア、音量、直近のステージ入口をブラウザ内に保存。続きからは入口で再開。mainへのpush後、GitHub Actionsでテストと素材検査が通った版をPagesへ公開します。

正本はこのREADMEのあるフォルダー。実機iOS／Androidのタッチ・音声は未確認です。提供素材の権利は各権利者に帰属します。
