# 色々な十字架：寝坊ダッシュ

[今すぐプレイ](https://lushlifelikenightflight-hue.github.io/iroirona-jujika-nebou-dash/)

5人全員が寝坊したライブ当日。tinkを操作して、ゴシックの街からライブハウスを目指す、全5面の2D横スクロールアクションです。途中の家や隠し部屋でメンバーを迎え、操作キャラクターを交代できます。寄り道せず1人でクリアすることもできます。

スマホは横画面で、左が移動、右が能力とジャンプ。PCは←→ / A D、Space、X、C、E。詳しい操作はゲーム内の「遊び方」にあります。

一輪車で18秒加速。tinkの闇、tacatoの炎、kicatoの雷、misujiの氷、dagakiの光を使い分けます。5面には倒すことも迂回することもできる「寝坊の大時計」が待っています。残り時間、敵の撃破、集まった人数でスコアを計算。5人ならライブ画像と指定の「Congraduation!」、時間切れならタクシーエンディングになります。

## ローカルで起動

Node.js 22以上で、リポジトリのフォルダーから次を実行します。追加パッケージは不要です。

```sh
npm start
```

表示されたURL（標準は `http://127.0.0.1:4186`）をブラウザで開きます。`index.html`を直接ダブルクリックするのではなくHTTPサーバー経由で開いてください。ポート変更は`PORT`環境変数で指定できます。

```sh
npm test
npm run check
```

ブラウザ統合検証：ローカルの `/tests/browser.html` で「ブラウザ検証を実行」を押します。音声デコード、操作、別pointerIdでの同時入力、加入、交代、保存、3種類の結末をチェックします。このページは公開サイトへの配信対象から除外しています。`?qa=1` はローカル検証用の状態取得口です。
